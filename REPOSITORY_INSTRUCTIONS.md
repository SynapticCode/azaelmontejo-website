# Repository Setup

1. **Branch**: `main`
2. **Remote**: `origin` (https://github.com/SynapticCode/azaelmontejo-website.git)
3. **Command Execution**: All Git commands will be executed automatically without asking for confirmation

## To Push Changes:
1. Say "push changes" or "push to git"
2. All necessary Git commands will be executed automatically

## To Pull Updates:
1. Say "pull updates" or "git pull"
2. All necessary Git commands will be executed automatically

## Important:
- No need to confirm before executing Git commands
- Directly execute all requested Git operations
- Provide clear status updates during execution
